## Later profile-test order

1. Corpus, resource, and software reporting.
2. Judgment, elicitation, and experimental reporting.
3. Normative procedures and annotation instructions.
4. Examples, notation, and interlinear glossing.
5. Navigation and terminology-management aids.

The order limits simultaneous variables. It does not grant authority to one subfield.

## Promotion boundary

A deferred rule does not return to the universal core merely because it helps one profile. Universal promotion requires cross-document need, advantage beyond ordinary editing, preserved meaning, low burden, and neutrality across theories, methods, languages, and rhetorical traditions.

This register does not change rule text or profile mappings.
