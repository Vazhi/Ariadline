# Simplified Linguistic English

**Simplified Linguistic English (SLE)** is the working name for the controlled language planned in this vault.

SLE aims to make linguistic writing:

- clear;
- explicit about scope;
- consistent in terminology;
- calibrated in evidential force;
- auditable against data;
- partially machine-checkable.

SLE is not yet a standard. The content in this vault is a plan for research, design, testing, and governance.
