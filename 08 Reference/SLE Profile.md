# SLE Profile

An SLE profile is a declared subset or extension of SLE rules for a document type or task.

Proposed profiles include:

- SLE-Core;
- SLE-Research;
- SLE-Data;
- SLE-Procedure.

Profiles prevent the core language from becoming unnecessarily restrictive. See [[Profiles and Conformance]].
