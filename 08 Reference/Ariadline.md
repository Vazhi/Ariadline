# Ariadline

**Ariadline** is the project name for the experimental linguistic reporting framework developed in this vault.

Ariadline aims to make linguistic writing:

- clear;
- explicit about scope;
- consistent in terminology;
- calibrated in evidential force;
- auditable against data;
- partially machine-checkable.

Ariadline is not yet a standard. The content in this vault is a plan for research, design, testing, and governance.
