# Linguistic Example

A linguistic example is a form or passage used as data, evidence, or illustration.

An example can be:

- attested;
- elicited;
- constructed;
- adapted.

Ariadline requires the author to identify the relevant status and provenance. See [[Linguistic Examples and Glossing]].
