# Controlled Natural Language

A controlled natural language is a natural language whose vocabulary, grammar, style, or interpretation is deliberately constrained for a defined purpose.

Controlled languages can prioritize:

- human comprehension;
- translation;
- consistency;
- formal interpretation;
- machine processing.

SLE is initially planned as a human-oriented controlled language. See [[SLE Architecture]].

The design must be evaluated against its actual users and tasks. A restriction that helps aircraft maintenance documentation does not automatically help linguistic argumentation.

See [[Standards and Sources]] for controlled-language research and ASD-STE100.
