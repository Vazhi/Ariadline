# Design Principles

## DP-01 — Preserve linguistic precision

A simpler sentence is not better when it removes a necessary contrast.

## DP-02 — Control ambiguity, not intellectual complexity

SLE must make a complex analysis explicit. It must not pretend that the analysis is simple.

## DP-03 — Separate functions

A sentence should normally perform one principal function:

- report data;
- state an analysis;
- state a hypothesis;
- define a term;
- give a requirement;
- identify a limitation.

See [[Claim-Evidence Matrix]].

## DP-04 — Use stable terminology

Use one preferred term for one defined concept within a project. Record accepted variants and prohibited substitutions in [[Term Inventory]].

## DP-05 — Make scope explicit

State the language, variety, speaker population, dataset, register, construction, or theoretical framework that limits a claim.

## DP-06 — Calibrate evidence verbs

Use different wording for **shows**, **supports**, **suggests**, **is consistent with**, and **does not establish**. See [[Normative Language]] and [[Claim-Evidence Matrix]].

## DP-07 — Support theoretical plurality

A project can define a term differently from another project. The writer must declare the definition and must not silently switch meanings.

## DP-08 — Prefer testable rules

Each normative rule needs:

- a rationale;
- compliant examples;
- noncompliant examples;
- boundary cases;
- a verification method.

Use [[SLE Rule Proposal Template]].

## DP-09 — Use layered conformance

Not every document needs every restriction. Use [[Profiles and Conformance|profiles and conformance levels]].

## DP-10 — Evaluate with users

Readability claims require controlled user tests. Automated scores are supporting measures, not substitutes for human evaluation.

## DP-11 — Maintain traceability

A rule must link to the problem data, decision record, tests, and change history.

## DP-12 — Prefer reversible early decisions

The pilot should test small, modular rules before it commits to a large fixed dictionary or a complete grammar.
