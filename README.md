# Ariadline Development Plan

This vault is a project plan for the development of **Ariadline (Ariadline)**.

Start with [[00 Ariadline Development MOC]].

## What this vault contains

- A project charter and defined scope.
- A proposed architecture for the language.
- Plans for controlled terminology, grammar rules, evidence statements, and linguistic examples.
- Conformance profiles and tooling requirements.
- Evaluation methods and acceptance gates.
- Governance, versioning, registers, and reusable templates.
- A source note that records the standards and research that informed the plan.

## Status

This is a **development plan**, not an approved Ariadline standard. All proposed rules and thresholds remain provisional until they pass [[Evaluation Framework|evaluation]] and [[Governance and Change Control|review]].
